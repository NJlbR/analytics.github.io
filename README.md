# СоциоПары

Статический одностраничный сайт для социологического и демографического исследования симпатий. Приложение работает на GitHub Pages без серверной части и хранит демонстрационные данные в `localStorage` браузера.

## Деплой на GitHub Pages

В репозитории есть workflow `.github/workflows/pages.yml`, который публикует сайт через GitHub Actions и официальный механизм GitHub Pages.

Workflow запускается:

- при `push` в ветку `main`, чтобы GitHub Pages не пытался деплоить preview/PR-ветки;
- вручную через **Actions → Deploy static site to GitHub Pages → Run workflow**.

Для работы деплоя в настройках репозитория откройте **Settings → Pages** и в блоке **Build and deployment** выберите **GitHub Actions**.

Файл `.nojekyll` оставлен, чтобы GitHub Pages не запускал Jekyll-обработку и отдавал статические файлы как есть.

## Важно о данных

Это статический прототип: регистрация, проверка уникальности username, анкеты и статистика хранятся только в `localStorage` конкретного браузера. Для реального исследования с общей базой участников потребуется подключить серверную базу данных или backend-as-a-service.
