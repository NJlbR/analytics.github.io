# СоциоПары

Статический одностраничный сайт для социологического и демографического исследования симпатий. Приложение работает на GitHub Pages без серверной части и хранит демонстрационные данные в `localStorage` браузера.

## Деплой на GitHub Pages

Чтобы избежать конфликтов между ветками из-за кастомных GitHub Actions workflow, сайт публикуется стандартным способом GitHub Pages из ветки репозитория:

1. Откройте **Settings → Pages** в репозитории.
2. В блоке **Build and deployment** выберите **Deploy from a branch**.
3. Выберите нужную ветку и папку **/(root)**.
4. Сохраните настройки.

GitHub Pages будет отдавать `index.html` из корня репозитория. Файл `.nojekyll` оставлен, чтобы Pages не запускал Jekyll-обработку.

## Важно о данных

Это статический прототип: регистрация, проверка уникальности username, анкеты и статистика хранятся только в `localStorage` конкретного браузера. Для реального исследования с общей базой участников потребуется подключить серверную базу данных или backend-as-a-service.
